# Daily Challenge - Day 2

## Topic: Advanced Git Operations & Pull Request Workflows

### Summary
Practiced pushing feature branches to remote repositories, opening Pull Requests on GitHub, and syncing local `main` with `git pull`.

### Key Learnings
- **Pull Requests:** Provide a clean way to review and merge feature branch code into `main`.
- **Syncing:** `git pull origin main` keeps the local working copy up to date with remote changes.
