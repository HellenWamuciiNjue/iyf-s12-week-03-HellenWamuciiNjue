# Daily Challenge - Day 1

## Topic: Version Control & Branching Fundamentals

### Summary
Today I set up a feature branch (`feature/daily-challenges`) to isolate work from the `main` branch. This follows Git best practices for collaborative development.

### Reflection / Key Learnings
- **Branching isolation:** Working on a separate branch allows building features without breaking production code on `main`.
- **Command used:** `git checkout -b <branch-name>` creates and switches to a new branch in a single command.
