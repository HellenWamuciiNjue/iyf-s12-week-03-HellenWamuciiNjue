# Daily Challenge - Day 3

## Topic: Collaboration Fundamentals & Merge Hygiene

### Summary
Worked with feature branches, submitted Pull Requests, and cleaned up merged remote branches on GitHub.

### Key Learnings
- **Branch Cleanup:** Deleting feature branches post-merge keeps the remote repository tidy.
- **Git Hygiene:** Frequently pulling `main` ensures the local workspace stays updated with remote changes.
