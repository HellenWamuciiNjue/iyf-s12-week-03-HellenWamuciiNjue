# Week 3: Developer Tools & Workflow

## About the Project
This repository tracks my hands-on mastery of advanced Git operations, industrial collaboration practices, and terminal history logging completed during Season 12 of the IYF Weekend Academy.

## Key Learnings & Practical Exercises
* **Isolated Feature Branching:** Developed a strong understanding of isolating day-to-day work onto separate feature branches to keep the production-ready main branch clean and reliable.
* **Remote Cleanups:** Practiced pruning obsolete remote records using explicit references to maintain clean, clutter-free repository states.
* **Staging and Scope Tracking:** Refined precision tracking workflows by selectively staging incremental folder modifications rather than grouping disjointed updates together.

## Challenges Faced & Breakthroughs
* **File Path Navigation:** Encountered initial friction tracing exact relative directory layouts within deeply nested folder trees. Resolved this by building a dedicated path history map using standard directory mapping structures.
* **Cross-Environment Constraints:** Managed unexpected machine-specific terminal configuration blocks by adapting pipelines directly into cloud-hosted web tracking interfaces to keep progress unblocked.
